# Cài Git & kéo code về máy

## 1. Cài Git

- Download and install Git:

```bash
https://git-scm.com/downloads
```

- Verify the installation:

```bash
git --version
```

## 2. Clone repository

```bash
git clone https://github.com/nhatquang-nguyen-129/display_lucky_draw.git
cd display_lucky_draw
```

Bước tiếp theo: [install-dependencies.md](./install-dependencies.md) — cài Node.js, dependency, và
các native build tool cần thiết trước khi chạy được app.
